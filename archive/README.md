# Original project

`original/` preserves the original Animal Tracking Game source and repository README. During installation, the existing `Animal Tracking Game/` directory is moved into this archive, including its original compiled classes.

These files are retained for provenance and are not compiled by the run or test scripts. The maintained application is in `src/`.

Original repository reference: b261c2f3aae9fa56d7057813224d9fcf4a3b6f47. `Landscape.java` was missing from that repository; the active source restores its rules from the provided bytecode and uses a new shared seeded random stream.
