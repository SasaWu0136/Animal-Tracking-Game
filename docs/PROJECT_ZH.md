# Wild Trails｜動物追蹤步道遊戲

Wild Trails 是以 Java 為核心的回合制步道遊戲。玩家與電腦巡林員輪流擲骰，沿著隨機產生的澳洲自然步道前進，透過動物目擊累積分數，並受到溪流、橋梁、倒木與土石滑落影響。

## 玩法

每次擲出 1–4 點。動物目擊與地形效果各有獨立的 50% 機率觸發。無尾熊 +10 分、鴯鶓 +7、袋熊 +5、袋鼠 +2，兔子 −5。

先抵達終點的人獲得 10 分加分，並立即結束遊戲。最後比較總分決定勝負，因此先到終點不一定獲勝；同分則平手。

## 互動功能

- 選擇簡單或複雜步道。
- 在編號棋盤查看兩位玩家的位置與地形。
- 即時比分、動物目擊圖鑑與完整回合紀錄。
- 固定亂數種子，重玩相同的步道與事件序列。
- 匯出文字探險紀錄。
- 桌面與手機版面、鍵盤操作及減少動態效果支援。

## 啟動

需要 JDK 17 以上。在專案根目錄執行：

```sh
sh scripts/web.sh
```

開啟 http://127.0.0.1:8082。Terminal 保持執行，按 `Ctrl+C` 停止。

命令列版本：

```sh
sh scripts/run.sh 42
```

輸入玩家名稱，選擇 `1` 或 `2`，再按 Enter 進行回合；輸入 `q` 離開。

## 設計

遊戲邏輯集中於 `GameEngine`，命令列與網頁使用相同規則。Java HTTP 服務保存本機遊戲狀態，前端以 HTML、CSS 與原生 JavaScript 呈現棋盤、比分與事件。

原始專案缺少的 `Landscape.java` 已依隨附編譯檔的步道規則重建。原始檔保留於封存目錄；目前版本可直接從原始碼編譯，不依賴舊的 class 檔。

## 驗證

```sh
sh scripts/test.sh
```

自動檢查涵蓋 400 場有固定種子的完整遊戲，核對重玩一致性、地形配置、移動邊界、分數與目擊紀錄，以及結算與輸入驗證。GitHub Actions 使用 Java 17 執行相同檢查。
